## M1 · 框架骨架（2-3 周）——纯文字对话 + 事件日志回放

### W1-1 后端脚手架与数据地基
- 目标：apps/backend 可启动；四张平台表（sessions/events/compensations/operation_logs）
  建好；EventStore 可写可读；BusinessBase 与操作日志管线就绪（02 §2.5/2.6）。
- 位置：`apps/backend/app/{main,core,platform/events,persistence}`；Alembic 初始迁移。
- 依赖：无。
- 验收：02 §6 验收清单全绿（seq 并发无跳号、ignorable fail-closed、崩溃恢复、
  derive_messages 折叠）。
- 依据：02 全文；dsh-02 B1-B5。

### W1-2 agent 执行链路接入（拷贝改造 agent_harness）
- 目标：executor/stream_bridge 拷贝件在平台事件总线下跑通：chat → SSE 全事件帧。
- 位置：`app/platform/agent/{executor,stream_bridge,event_translator}.py`。
- 依赖：W1-1。
- 验收：turn/step/chunk/message/tool 全帧落库 + 下发一致；断线 run 不终止、重连无缺口。
- 依据：01 §4 复用清单；03 §2；agent_harness `executor.py`。

### W1-3 插件加载器 + 设置/凭证最小版
- 目标：`plugins/*/backend` 自动发现装配；fail-loud；域白名单；凭证引用制。
- 位置：`app/platform/plugins/`；`templates/plugin-template/`。
- 依赖：W1-1。
- 验收：05 §7 前三项（重名/缺 schema/坏清单启动失败；模板插件新增成功）。
- 依据：05 全文；dsh-12 I/H。

### W2-1 前端壳骨架
- 目标：React 壳 + SSE 客户端 + 纯文字对话链路 + 主题 FOUC + locale 两段式。
- 位置：`apps/frontend/src/{shell,transport,state,primitives}`。
- 依赖：W1-2（联调）。
- 验收：对话可用；刷新回放重建完整会话；断网恢复不清屏。
- 依据：04 §1/2/5/6。

### W2-2 Assembler + contracts 流水线 + CI
- 目标：ConversationAssembler（事件族折叠）+ schema 双端生成 + 全部 CI 门禁。
- 位置：`apps/frontend/src/registry`；`packages/contracts`；CI 配置。
- 依赖：W2-1。
- 验收：04 §8 Assembler 回放测试；03 §4 `gen.py --check`；07 §7 表全绿。
- 依据：04 §3/4；03 §4。

**M1 完成标准：纯文字对话全链路（含刷新回放、断线重连、插件加载、CI 门禁）可用。**

## M2 · 组件渲染链路（2 周）

### M2-1 组件闭环
- 目标：模型调工具 → `component/request` SSE → 前端 Lazy 组件渲染 → update/submit
  REST → 事件落库 → resume 续跑。
- 位置：`app/platform/agent`（interrupt 桥）；`apps/frontend/src/registry`（渲染路径）。
- 验收：demo-table 插件（简单表格）全链路；07 §2 interrupt 生命周期测试
  （cancel/interrupt_id 校验/双组件）。
- 依据：03 §2/§3；04 §2/3；07 §2。

### M2-2 注入与投影
- 目标：submit 摘要 inject（不唤醒）；stats 投影 + `projection` 帧。
- 验收：填报摘要出现在下一次模型上下文；会话列表显示统计与 pendingInteraction。
- 依据：07 §5；02 §4；dsh-04 §4。
